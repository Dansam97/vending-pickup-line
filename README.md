Entry for the make.fun bounty "One Line, One Minute: The Vending Machine Pickup Line Contest". The program writes one pickup line, spoken by a vending machine to a passing human, to `entry.txt` in the output directory: a machine-voiced line built from the machine's own world of coils, slot buttons and exact change, with the punch landing in the last few words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
